# Sort-In-Sync
Rhythm Game Made In Java using Swing


# !IMPORTANT!
If you dont have SQLite download this:
[DOWNLOAD SQLITE](https://github.com/xerial/sqlite-jdbc/releases/download/3.53.4.0/sqlite-jdbc-3.53.4.0.jar)

Then you should place it inside the Libraries Folder:
- Right Click Libraries
- Add JAR/Folder
- Locate where you downloaded the SQLite
- Try running the database by instantiating a Database Object
